Loan Predictor

This project uses K-Nearest-Neighbors to classify individuals based on their ability to repay a loan based on income. A variety of K values are tested, with the best used to create a model used to predict the status of an individuals
ability to repay a loan. 

loan.py contains the python script used to create the model and perform the analysis.

accuracy_vs_k.png is a line chart that shows the accuracy metric for each value of K tested with the model. This is used to determine the most accurate value of K to use in the final model.

confusion_matrix.png is a confusion matrix that visually demonstrates the number of true positives/negatives, and false positives/negatives from the models predictions.
